# CCW_Dep
This study uses data from a nationally representative Norwegian study of adolescents (Ungdata 2022) to examine patterns of climate change worry within a subsample with high levels of depressive symptoms.

The current repository consists of the following scripts: 
01 DATA PREPROCESSING
02 PRESPECIFIED MAIN ANALYSIS
03 SENSITIVITY PPO ANALYSIS
04 IPW ANALYSIS [FINAL PRIMARY]
05 SENSITIVITY HIGH P-FACTOR
06 SENSITIVITY COMPLETE-CASE ANALYSIS
07 SENSITIVITY NON-DEPRESSED SAMPLE
08 FIGURES
